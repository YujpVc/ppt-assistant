# 视觉方向：从“不错”到“惊艳”

不是加装饰，是先立主角。每套 deck 在 brief 阶段就定下面五项。

## 1. 一页 hero

- **每 5 页最多 1 页 hero**：5 页恰好 1 页，10 页最多 2 页；用户指定页数时按比例，不把 5 页当特例。
- hero 是整页机制图/状态账本/满幅图，占版面 55–65%，不是三张等宽卡。
- 其余页做支撑，不抢 hero；不要每页平均用力。

## 2. 一套明暗

- 先定 tonal system：深色封面 → 至少 1 页深色内容页做桥；或全浅色 + 一个深色机制页。
- 禁止“深→深→白→白→白”的断裂；白底卡页连续出现时，必须有一页深色/满幅图打断。
- 主色 60 / 墨 30 / 强调 10；语义色只做状态。

## 3. 一句大字

- 每页只留一个 **40–54pt** 结论句；正文 9–10pt，指标/来源 8pt。
- 标题不是栏目名；不要把标题、导语、卡标题做成同一重量。
- 一页只承担一个判断；第二句结论删掉或降为小字。

## 4. 一种图法

- 图片要么满幅 + 渐变蒙版，要么图上标注；不要小图塞在表格旁当装饰。
- 图注必须与画面一致；通用场景不占证据位。
- 没有信息角色的图删掉，空位给机制/证据。

## 5. 一处不对称

- 至少一页用 7/5 或 8/4 分栏；不要连续三页 3 等分/2×2 等权。
- 等权四柱必须有分组/阶梯/对照隔断；否则改成不对称主次。

## 6. 记忆点测试

审查时每页回答一句：**“这一页最让人记住的是什么？”**

- 答不出 → 这页是模板，必须改；
- 所有页都答“信息齐全” → 整套没有 hero，必须重排；
- hero 页答不出 → 整套不通过。
